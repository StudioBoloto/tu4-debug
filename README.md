# TU4 Debug

Браузерный эмулятор машины Тьюринга в четвёрках для лабораторных работ первого курса МАИ.

TU4 Debug сохраняет формат программ jstu4 2.3 и расширяет его средствами пошаговой отладки.

## Возможности

- пошаговое выполнение и отмена выполненных шагов;
- брейкпоинты по строкам программы;
- выполнение до указанного состояния;
- подсветка следующей команды;
- отображение состояния, позиции головки и текущего символа;
- пронумерованные ячейки ленты с явным обозначением пробела `␠`;
- статистика команд, операций и использованных ячеек;
- автоматическое сохранение программы и входной ленты;
- импорт и экспорт программ в формате `.tu4`.

## Формат программы

Команда записывается в формате `q,a,v,q'`, где:

- `q` — текущее состояние;
- `a` — символ под головкой;
- `v` — записываемый символ или действие;
- `q'` — следующее состояние.

Действия:

- `<` — сдвиг влево;
- `>` — сдвиг вправо;
- `=` — остаться на месте;
- `#` — остановка;
- любой другой одиночный символ — запись в текущую ячейку.

Поддерживаются именованные состояния, несколько команд в строке и комментарии `//` или `#`. Числовые состояния нормализуются: `01` и `1` считаются одним состоянием. Начальное состояние — `0`.

## Управление

- `Старт` — начать заново и выполнить первую команду;
- `Шаг` — выполнить одну команду;
- `Назад` — отменить один шаг;
- `До конца` — продолжить до остановки или брейкпоинта;
- `Дойти` — продолжить до указанного состояния.

Горячие клавиши:

- `Ctrl/Cmd + Enter` — старт;
- `F5` — выполнить до конца или брейкпоинта;
- `F10` — шаг вперёд;
- `Shift + F10` — шаг назад;
- `Esc` — пауза.
